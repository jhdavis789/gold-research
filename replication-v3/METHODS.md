# Frozen version 3 quantitative design

Definitions frozen before this version's performance computation. Preserve versions 1 and 2. The universe keeps NEM, AEM, B, AU, FNV, WPM, RGLD and adds GFI, KGC, HMY, EGO, IAG, BTG and OR. These are selected surviving US-traded gold producers and a royalty company; this is not a survivorship-free sector sample. Each stock receives its longest feasible history and an explicit paired common-period comparison. No mining index or peer return enters a replica.

The implemented instrument remains funded GLD and cash BIL, optionally SLV. It is not measured futures P&L. Costs: 2bp per fund-notional trade, 50bp annual incremental spread on negative cash, 5% of hypothetical option premium per entry or pre-expiry sale; no tax or integer-share restriction. Quantities remain fixed between monthly or quarterly trades. Account NAV includes cash, funded shares and option marks. At expiry the option pays its intrinsic value into cash; trading sells old contracts and purchases new ones. No fitted intercept, free squared gold payoff or undisclosed alpha is earned. Terminal liquidation and fresh-entry fees are charged.

Training and execution use the same self-financing simulator and monthly return-error objective, including trading and financing charges. A fit at month-end t uses 24 months of observations ending at month-end t-1, leaving a full month information gap; trading at t then holds the chosen quantity. A 60-month gold-quarterly sensitivity is predeclared. Training replays a constant target allocation with the same quarterly/monthly holding and financing mechanics; actual evaluation re-estimates that allocation at each scheduled trade. Scheduled quarterly dates use the original evaluation calendar, and fresh-window entry uses the already available decision and pays entry fees.

Candidate families: gold monthly/quarterly; gold+silver monthly/quarterly; gold+illustrative calls/puts monthly/quarterly; gold+silver+illustrative calls/puts monthly/quarterly; gold quarterly with 60-month estimation. Gold exposure is bounded [0,3] times NAV, silver [0,1], long call/put quantities [0,1] units of underlying-notional per NAV each. Augmented families independently constrain extra weights, so every baseline solution remains feasible when extra weights are zero.

Options are hypothetical European ATM GLD calls/puts, expiry at the next scheduled rebalance, priced in dollars by Black-Scholes from lagged BIL rate and observed GVZ mark volatility (flat term structure, no observed option surface). Premiums, cash opportunity cost, expiry payoffs and spreads are paid. Prices are modeled premiums; these are not actual historical option execution observations. A separate actual-data access report governs whether observed historical contracts can replace this illustration. Before options history exists, those candidates are unavailable, never filled from later volatility.

For every augmented fit, evaluate the baseline embedding and solve the unpenalized tracking-SSE objective. Retain whichever feasible candidate has lower SSE, which guarantees the retained best-known fit never exceeds the embedded baseline. The mathematical global optimum cannot be worse because the feasible set includes the baseline. This guarantee concerns in-sample fit, not held-out returns or a numerical proof of global optimality. For deployed augmented estimates, a fixed 0.0002 penalty on extra exposure squared shrinks toward the zero-extra baseline. The gold coefficient itself has no penalty in either family. Retain raw and penalized objectives and all candidate definitions; no model is selected on evaluation performance.

Risk-matched benchmark: trailing 36-month observed stock/GLD monthly volatility ratio, capped at 3, set using observations ending t-1 and traded monthly or quarterly. Optional ex-post full-period stock/gold volatility ratio is a diagnostic only, labeled with lookahead. Its performance cannot be used as an implementable strategy claim.

Report honest monthly return tracking R² = 1 - sum(replica-stock)^2/sum(stock-mean(stock))^2, tracking error, volatility, CAGR, drawdown, turnover, entry/exit costs and paired-period results. Rolling 1,3,6,12,36,60,120 month windows each open a fresh account; retain each overlapping window and report the number of disjoint windows separately. Overlapping windows are not independent evidence. Block-bootstrap uncertainty uses 12-month blocks of paired realized monthly return errors; it does not refit parameters or solve survivorship/specification uncertainty.

## Calendar correction after independent review

The first version 3 output accidentally scheduled quarters relative to each instrument history's first eligible row. That confounded instrument additions with different calendar quarter phases. Its complete results and engine sources are preserved under `results/phase_confounded_*`; do not use them for fair instrument comparisons. Corrected families trade at a shared first eligible entry per stock across the 24-month replica/option and 36-month risk requirements, then every calendar March/June/September/December (monthly families every month). The 60-month sensitivity starts later. Training follows this same global quarter calendar. At a fresh entry between quarters, the first option expires at the next calendar quarter, so its initial life can be one or two months; it is never silently set to three months when an earlier scheduled trade intervenes. Subsequent initial accounts, full-period replay, supplemental silver options and duration hypotheses use the same rule.
